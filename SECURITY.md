# Security policy

## Supported versions

Only the latest minor release line gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub's security advisory form: https://github.com/kostas-01/loadlens-html/security/advisories/new

Include the affected version and steps to reproduce. If the problem is in a generated report (for example, unescaped content from a `report.json`), include a minimal `report.json` that shows it. You should get a reply within 7 days.
